# Dataset

This directory is intended to contain the dataset used in the MBTI personality type classification project.

## Dataset Information

- **Dataset Name:** MBTI Dataset
- **Total Records:** 43,744
- **Total Features:** 9
- **Target Variable:** Personality

## Dataset Source

The dataset used in this project can be accessed through the following link:

[MBTI Dataset – GitHub](https://github.com/naufalfrdss/Data_Sains/blob/main/datakotor.csv)
