Notebooks

This directory contains the Jupyter Notebook used for MBTI personality type classification and analysis.

Notebook

personality_type_classification.ipynb — Contains the complete workflow, including data exploration, preprocessing, feature selection, model training, and evaluation.

How to Run

1. Clone the Repository

git clone https://github.com/RaisB17/personality-type-classification.git

2. Navigate to the Project Directory

cd personality-type-classification

3. Install Dependencies

pip install -r requirements.txt

4. Open the Notebook

Launch Jupyter Notebook:

jupyter notebook

Then open:

notebooks/personality_type_classification.ipynb

Alternatively, upload the notebook to Google Colab and run it there.

Dataset

The notebook loads the dataset directly from its original GitHub source. An internet connection is required to retrieve the dataset.
