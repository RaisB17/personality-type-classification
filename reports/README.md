# Project Report

This directory contains the final report for the MBTI Personality Type Classification project.

## Report Contents

The report documents the complete project workflow, including:

- Business Understanding
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Feature Selection
- Machine Learning Modeling
- Model Evaluation
- Streamlit Deployment

## Best Model

The final evaluation identified Random Forest with IQR preprocessing as the best-performing model.

| Metric | Score |
|---|---:|
| Accuracy | 93.76% |
| Precision | 93.81% |
| Recall | 93.76% |
| F1-Score | 93.76% |
